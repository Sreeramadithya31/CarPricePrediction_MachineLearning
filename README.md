# Car Price Prediction with Machine Learning 🚗

A machine learning project that predicts the price of a car based on various features such as brand, horsepower, mileage, and other vehicle-related attributes.

The project involves data preprocessing, feature engineering, exploratory data analysis, and regression model development to estimate car prices and evaluate prediction performance.

### Objectives
- Analyze car-related features affecting vehicle prices.
- Clean and preprocess the dataset.
- Perform feature engineering.
- Build a regression model to predict car prices.
- Evaluate model performance.

### Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

### Project Outcome
Developed a machine learning regression model to estimate car prices using vehicle specifications and related features.
