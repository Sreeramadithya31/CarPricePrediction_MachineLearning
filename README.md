# CodeAlpha - Car Price Prediction with Machine Learning

## Objective
Build a regression model that estimates vehicle prices from available vehicle attributes.

## Tools
Python, Pandas, Scikit-learn, Matplotlib and Seaborn.

## Dataset setup
1. Download the car-price dataset linked in your CodeAlpha instructions.
2. Save it as `data/CarPrice_Assignment.csv`.
3. The starter code expects a target column named `price`, as used in the commonly distributed automobile price dataset.
4. Review the dataset's license and attribution before publishing it.

## Run in VS Code
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## Methodology
- Inspect the dataset and remove the identifier column `car_ID`, if present.
- Clean the target price and discard invalid/non-positive target rows.
- Separate numeric and categorical predictors automatically.
- Impute missing numeric and categorical values.
- Scale numeric features and one-hot encode categorical features.
- Train a Random Forest regression model.
- Evaluate using MAE, RMSE, R-squared and five-fold cross-validation.
- Save predictions and diagnostic plots.

## Outputs
- `outputs/metrics.json`
- `outputs/predictions.csv`
- `outputs/actual_vs_predicted.png`
- `outputs/residual_distribution.png`

## Evaluation notes
MAE and RMSE are expressed in the dataset's price units. R-squared measures the proportion of target variance explained by the model on the test split. Results must be generated by running the code; do not invent performance figures.
